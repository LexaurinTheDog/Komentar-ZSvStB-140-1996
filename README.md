# Komentář k zákonu č. 140/1996 Sb., o zpřístupnění svazků vzniklých činností bývalé Státní bezpečnosti

Otevřený komentář k zákonu o zpřístupnění svazků vzniklých činností bývalé Státní bezpečnosti — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; Archiv bezpečnostních složek, oprávnění žadatelé, zpřístupnění a zveřejnění dokumentů, ochrana osobních údajů a sdělení pravých jmen.

Konsolidované znění: dokument e-Sbírky `SB-1996-00140_2022-02-01`.
